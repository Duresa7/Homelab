# Operations

**Created:** 2026-07-09  
**Last updated:** 2026-09-06

Operations holds records that cross more than one platform or infrastructure owner:

- `Inventory/` - the living Galaxy inventory files plus the dated snapshots that preceded them
- `Maintenance/` - cross-system maintenance records
- `Evidence/` - retained command output and checks for cross-system work

I keep shared inventory, maintenance history, and evidence here. Raw diagnostic output such as SMART results lives with the hardware under `Infrastructure/Hardware/Components/Drives/`; there is no `Diagnostics/` folder here, which this file claimed until 2026-09-06. Service changes and troubleshooting stay with their owner.
