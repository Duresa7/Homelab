# Operations

**Created:** 2026-07-09  
**Last updated:** 2026-07-29

Operations holds records that cross more than one platform or infrastructure owner:

- `Inventory/` - dated current-state and historical inventories
- `Maintenance/` - cross-system maintenance records
- `Diagnostics/` - raw diagnostic output such as SMART results
- `Evidence/` - retained command output and checks for cross-system work

I keep shared inventory, maintenance history, evidence, and raw diagnostic output here. Service changes and troubleshooting stay with their owner.
